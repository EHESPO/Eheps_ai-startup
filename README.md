🔗 Stellar & Web3 Research

EHEPS AI Startup includes research into public blockchain data, with a focus on the Stellar ecosystem.

The project may utilize the public Stellar Horizon API for:

- Ledger analysis
- Transaction analysis
- Payment tracking
- Operation monitoring
- Account activity review
- Asset research
- Blockchain transparency
- Public data verification

Stellar Horizon

https://horizon.stellar.org

Example:

https://horizon.stellar.org/ledgers/63906755

The system is designed strictly for read-only analysis of publicly available blockchain data.

It does not require or request private wallet credentials.

🔐 Responsible AI & Security

Security, privacy, and responsible technology are foundational principles of this project.

We do not store:

- Private keys
- Seed phrases
- Recovery phrases
- Passwords
- Wallet signing credentials
- Authentication secrets

Only publicly available blockchain data (such as addresses and transaction hashes) may be analyzed.

Security principles:

- Zero-trust architecture
- Least-privilege access
- Secure secrets management
- Data minimization
- Full auditability
- Human oversight
- Responsible AI practices
- Public-data verification
